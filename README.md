# ASCII Sun and Moon

This project is an animated ASCII art visualization of the sun and moon merging together to create the earth, built using HTML5 Canvas, JavaScript, and custom procedural math functions to render shaded planetary spheres, stars, and meteors in real time. It features synchronized audio playback using Title Fight's "Head in the Ceiling Fan" with a dual-audio crossfade mechanism for smooth looping, alongside an interactive dark overlay that triggers full-screen mode on click to bypass browser autoplay restrictions.

## Files

* index.html
* audio.js
* head_in_the_ceiling_fan.ogg
* style.css
* SunAndMoon1.44.36 PM.py

## How to Run

1. Clone or download the repository to your laptop.
2. Ensure `head_in_the_ceiling_fan.ogg` is placed in the exact same folder as the HTML and JavaScript files.
3. Open `index.html` in any modern web browser or deploy the folder directly to Netlify.
4. Click anywhere on the overlay to launch full-screen mode, start the animation, and play the music at the same time.
